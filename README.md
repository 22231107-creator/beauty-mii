# Beauty by MI&I - ReactJS Web Application

## Project Description
A responsive beauty brand website built with ReactJS. The website provides information about the brand, displays best-selling products, and allows users to contact the business.

## Pages
- **Home** - Hero section with brand message and three service categories
- **About** - Information about the brand and its values
- **Products** - Display of best-selling products with images and prices
- **Contact** - Contact information and a contact form

## Technologies Used
- ReactJS
- React Router DOM
- CSS3
