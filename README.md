# Beauty by MI&I - ReactJS Web Application

## Project Description
A responsive beauty brand website built with ReactJS.

## Pages
- Home
- About
- Products
- Contact

## Technologies Used
- ReactJS
- React Router
- CSS3

## Setup Instructions

1. Clone the repository:
   git clone https://github.com/22231107-creator/beauty-mii.git

2. Install dependencies:
   npm install

3. Run the project:
   npm start

## Deployment
Live at: https://beauty-mii.vercel.app
